# Contributing

Thanks for helping improve this independent starter project.

## Development setup

1. Use Python 3.9 or newer.
2. Create and activate a virtual environment.
3. Install dependencies with `python -m pip install -r requirements.txt`.
4. Run the tests with `pytest`.

No OpenAI API key is required to run the application or its tests. Avoid adding credentials, personal information, or confidential business data to commits and test fixtures.

## Changes and pull requests

- Keep changes focused and compatible with the project's Python version.
- Add or update focused tests for behavior changes.
- Confirm `pytest` passes before opening a pull request.
- Describe the behavior changed and any relevant limitations in the pull request.
